# Overview

This documentation describes the functionality and implementation details of `PassLLM/main-condition-operation-match.py`.
The functionality of `main-condition-operation-match.py` is to match concrete MLIR operations from the conditions generated by `PassLLM/main-pass-analyze.py`.

# Dependent Files

- `PassLLM/RAG/rag.py`: which provides functionality to search the source code of MLIR.

- `PassLLM/LLM/llm.py`: which provides basic functionality to ask LLM.

- `PassLLM/LLM/prompts`: which provides the prompt files for each step.

# Overall Description

## `load_condition` function(written)
- Aim: to load `pass_pattern_conditions` from `condition_file`
- Input:
	- `condition_file`: the json condition file generated by `PassLLM/main-pass-analyze.py`, using `--condition-file` option to receive this parameter.
- Output: 
	- `pass_pattern_conditions`: the optimization/transformation condition for `pattern_name` rewrite pattern in `pass_name` pass.

## `operation_match` fucntion(written)
- Aim: to match some specific operations to a given pass_pattern_condition.
- Input:
	- `pass_name`: the pass name.
	- `pattern_name`: the pattern name.
	- `conditions`: the conditions.
- Output: 
	- `operations`: the operations that should trigger the `pattern_name` rewrite pattern in `pass_name` pass.
- Details(pseudocode):
	```python
	operations = extract_operation_condition(pass_name, pattern_name, conditions)
	if operations:
		return operations
	
	interfaces = extract_interface_condition(pass_name, pattern_name, conditions)
	if interfaces:
		operations = find_op_by_interfaces(interfaces)
		if operations:
			return operations

	traits = extract_trait_condition(pass_name, pattern_name, conditions)
	if traits:
		operations = find_op_by_traits(traits)
		if operations:
			return operations

	dialects = extract_dialect_condition(pass_name, pattern_name, conditions)
	if dialects:
		operations = find_op_by_dialects(dialects)
		if operations:
			return operations
	
	return deal_no_op_condition()
	```

## `extract_operation_condition` fucntion
- Aim: to find the operation that may trigger `pattern_name` rewrite pattern in `pass_name` pass.
- Input: 
	- `pattern_name`: the pattern name.
	- `pass_name`: the pass name.
	- `conditions`: the conditions for triggering `pattern_name` rewrite pattern in `pass_name` pass.
- Output: 
	- `operations`: the operations required by `pattern_name` rewrite pattern in `pass_name` pass.
- Details:
	
	This function calls LLM, the system prompt is `PassLLM/LLM/prompts/1.analyze.system.md`, the prmopt template of this step is `PassLLM/LLM/prompts/2.1.operation-match.operation.md`. `PassLLM/LLM/prompts/2.1.operation-match.operation.md` receives two parameters, i.e., `${pattern_pass_string}` and `${pass_pattern_condition}`.
	
	The `${pattern_pass_string}` can be constructed via "`${pattern_name}` pattern in `${pass_name}` pass" when `pattern_name` is not None, and it can be constructed via "`${pass_name}` pass" when `pattern_name` is None.
	
	The `${pass_pattern_condition}` is the `"\n".join(conditions)`.

## `deal_no_op_condition` fucntion
- Aim: deal with no operation condition is found, currently it returns all operation.
- Input: None
- Output: 
	- `operations`: all operation name.
- Details:

	Mainly how to construct the operations. The list of all operations can be obtained from `PassLLM/RAG/opname.to.class.txt`. The format of each line of this file is `dialect_name.operation_textual_name => operation_class_name`. The operation name expected by this fucntion is `dialect_name::operation_class_name`.

## `find_op_by_interfaces` function

- Input:

- Output:

- Details(pseudocode):
	
	```python

	operations = # get all operations from PassLLM/RAG/opname.to.class.txt, like `deal_no_op_condition` function

		if any(interface.lower() in op_tablegen_code.lower() for interface in interfaces):
			target_ops.append(op)
	```
